
# Olá, eu sou o Samuel! 👋

### 💻 Desenvolvedor Full Stack

Sou apaixonado por tecnologia e pelo desenvolvimento de aplicações web modernas, eficientes e escaláveis, sempre com foco na experiência do usuário.

Tenho experiência no ecossistema **JavaScript/TypeScript**, trabalhando principalmente com **Vue.js e Node.js**, além de outras tecnologias para o desenvolvimento de soluções completas.

Valorizo **código limpo, boas práticas, arquiteturas bem estruturadas e testes automatizados**, buscando sempre qualidade, performance e facilidade de manutenção.

Estou sempre em busca de novos desafios, aprendizados e oportunidades para compartilhar conhecimento.
